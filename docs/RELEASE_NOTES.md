## Open Listener 0.1.14

- 记录详情页删除返回箭头旁的“文字记录”，标题增加下划线并可点击重命名；重命名默认选中全部文字并自动弹出键盘，两行输入框。
- 记录详情新增编辑模式开关，开启后可点击每条原文／译文进行修改并立即保存；编辑模式显示原始分句，正常阅读沿用标点合句。
- 播放已保存录音时，字幕按录音时间自动滚动并高亮对应句子，支持拖动播放条后定位；校准细进度条与滑块的对齐。
- 主页缺少模型的提示统一为“请配置语音／翻译／语音与翻译模型”，配置按钮直接跳转相关设置内页；删除自动保存文字的冗余提示。
- 删除记录分享菜单中“导出 MD / PDF”，保留分享与复制；设置页 GitHub 右侧增加 by Vexpaer。
- 语言选项简化为“从／翻译为”（From / To）。
- 胡萝卜按钮白色描边加厚；暖色调字体通过全局文字样式继承衬线字体。
- 桌面组件新增清晰渐变背景和图标操作，支持已有权限时点击直接开启麦克风前台服务，失败则打开 App 请求权限。

Android 8+ · ARM64 手机下载 `OpenListener-v0.1.14-arm64-v8a.apk`，与已安装版本签名一致时支持覆盖更新。
