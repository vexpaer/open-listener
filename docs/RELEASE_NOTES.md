## Open Listener 0.1.9

- 修复切换主题颜色后背景仍然为蓝色：背景渐变和光晕同步使用主题配色，兼容深浅模式。
- 背景运动速度提高到两倍，完整周期由 160 秒缩短至 80 秒。
- 删除主题颜色 HEX 输入框，将最后一个粉色圆替换为彩色圆；点击打开选色盘，支持色相、饱和度和亮度。
- 本地 / 云端模型按钮与下方内容的连接处改用直角贴合，选中底色横向滑动。
- 记录分享按钮替换为向上箭头托盘线框图标。
- 更新中英文 README。

Android 8+ · ARM64 手机下载 `OpenListener-v0.1.9-arm64-v8a.apk`，支持原签名覆盖更新。
