## Open Listener 0.1.13

- 背景动态运动周期由 40 秒缩短为 20 秒，纯色模式保持静态。
- 新增 Android 桌面实时字幕小组件，支持启动、暂停、继续和结束；首次启动从可见应用页面获取麦克风权限。
- 开始聆听按钮使用带细白边的 🥕 胡萝卜图案，按钮底色加深。
- 录音空白页图标颜色加深，主文案缩小一级并改为黑色。
- 暖色主题自动启用 Noto Serif 风格的衬线字体，冷色维持无衬线字体。
- 云端语音与翻译配置改为可添加的独立配置列表；一个服务商可存储多个凭据组合并选择其中之一，旧配置首次使用时迁移。
- 更新进度与安装按钮移到版本描述上方，“交给系统安装”改为“安装”。
- 移除通知面板音量条，保留实时字幕和录音控制。
- 缩小录音页字幕模式切换附近间距，按钮标签居中。
- 新建记录标题不再包含 Lecture。
- 本地/云端模型选项取消滑动动画，切换立即生效。
- 历史录音的进度轨道变细、滑块变小，移除右侧总时长。

Android 8+ · ARM64 手机选择 `OpenListener-v0.1.13-arm64-v8a.apk`；原签名覆盖升级。
