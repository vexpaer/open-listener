## Open Listener 0.1.17

- 本地语音模型下载、解压、安装和使用不再计算或校验 SHA-256；移除重复读取模型权重与压缩包的耗时步骤。
- 去掉安装过程中的测试音频预推理；模型在真正开始识别时才初始化。
- 增大解压读写缓冲区；解压中实时显示已处理的 MB 数，便于判断是否仍在进行。
- 新本地模型下载并安装成功后自动选中该模型、切换语音识别至本地引擎，并刷新首页状态。
- 保留 HTTPS、下载总大小和解压文件大小／路径安全检查；兼容此前已安装的本地模型。
- App 内置更新器取消下载和安装前的 APK SHA-256 重算；仍检查 APK 包名、版本、架构与安装证书一致性。
- 为兼容旧版更新器，GitHub Release 继续提供原有的 update.json 与 SHA256SUMS 元数据。

该变更降低了文件完整性检查的强度；仅从官方来源下载模型。
