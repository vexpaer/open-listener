## Open Listener 0.1.6

- 设置页改为语音识别、文字翻译、语音保存三条紧凑行，箭头和开关放在右侧。
- 检查更新、下载更新按钮始终并排显示，缩短中英文文案。
- 记录详情的复制、导出与分享收进标题右侧 📤 菜单；正文改为一个连续阅读区。
- 本地模型卡片压缩信息和高度，来源、许可证、删除收进更多菜单。
- API 教程改为步骤卡片与官方链接卡片。
- 新增文字每字 90 ms 渐入，原有文字保持稳定。
- 开始、暂停、继续、结束按钮增加渐变、细边、阴影与按压回弹。
- 录音时顶部标签背景显示真实音量驱动的柱状动画，透明度 30%；暂停后停止，支持减少动态效果。

Android 8+ · ARM64 手机下载 `OpenListener-v0.1.6-arm64-v8a.apk`，通用版支持 ARM64 / x86_64，可原签名覆盖更新。
