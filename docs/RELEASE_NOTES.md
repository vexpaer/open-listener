## Open Listener 0.1.7

- 顶部录音音量柱透明度从 30% 降至 15%。
- 字幕默认跟随到最底部，临时字幕和译文在同一段内增长时也会持续跟随。
- 手动上滑查看历史即暂停跟随，滑到最底部自动恢复，也可点击“回到最新”。
- 新增“豆包同传”入口，使用同声传译 2.0 的 S2T 模式，直接显示原文与译文字幕，不请求或播放译音。
- 同传只需配置 API Key，无需额外的翻译服务；原文和译文会保存在同一条记录中。
- 改善同传暂停/继续、最终字幕确认与中断状态处理。

使用：设置 → 语音识别 → 云端模型 → 豆包同传。先在火山引擎开通同传 2.0，再保存有权限的 API Key；在设置首页选择源语言和目标语言。

Android 8+ · ARM64 手机下载 `OpenListener-v0.1.7-arm64-v8a.apk`，可原签名覆盖更新。
