## Open Listener 0.1.11

- 豆包同传 WebSocket 意外断开后自动恢复，短时音频在内存中排队等待新连接，最多重试四次。
- 长时间有语音输入却无豆包响应时，尝试主动重新连接；权限错误（HTTP 401/403）不会无意义重试。
- 录音页面提示连接恢复状态，超过缓冲容量则明确报错，避免静默丢失音频。
- 豆包原文和译文根据句末标点自动组合完整句子；实时字幕与历史记录保持一致。
- 历史记录的复制、Markdown / PDF 和全部 ZIP 导出同样使用合并后的句子；原始分句保留，以支持后续译文修订。
- 增强豆包鉴权：兼容新版 API Key 与旧版 App ID / App Key + Access Token，改进 403 权限提示与追踪 ID。

Android 8+ · ARM64 手机下载 `OpenListener-v0.1.11-arm64-v8a.apk`，支持原签名覆盖更新。
