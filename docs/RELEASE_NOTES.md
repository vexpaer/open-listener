## Open Listener 0.1.5

- 支持左右滑动切换录音、记录、设置，并与顶部标签同步。
- 英文首页改为 “Listen clearly. Read along.”。
- 语音识别与文字翻译改为独立的二级设置入口，页内顶部切换本地 / 云端模型。
- 新增英语专用 Zipformer INT8 本地识别模型，可下载、选择与删除。
- 启用阿里云 Qwen-ASR、OpenAI 与自定义兼容语音接口，支持填写模型 ID；豆包继续使用实时流式识别，其他接口按短音频分段识别。
- 删除记录页空状态说明，设置底部链接改为 Github。
- 新增“保留录音”开关，默认关闭；保留音频的记录显示 🎧，支持应用内播放，删除记录时一并删除音频。
- 从旧版升级保留已有文字记录。

Android 8+ · ARM64 手机安装 `OpenListener-v0.1.5-arm64-v8a.apk`，通用版本支持 ARM64 / x86_64。可通过应用设置检查更新，使用原签名覆盖安装。
