## Open Listener 0.1.16

- 修复“模型已经配置却仍然提示请配置模型”：启动和模型／语言／服务商配置变化后自动检查所选引擎；旧检查会取消，防止覆盖新选择；区分未检查、检查中、需要下载、缺少凭据与运行时不可用。
- 新增 SenseVoice Small INT8（中、英、日、韩、粤），使用 sherpa-onnx 离线识别与分段字幕输出。
- 新增 X-ASR 480ms 中文／英文流式 INT8 版本（含标点）。
- 新增 Moonshine v2 English Tiny 与 Base，支持本地分段识别。
- 四个新模型均取自 sherpa-onnx 官方模型发布页，归档大小及 SHA-256 固定在模型目录中。下载器采用官方归档校验、受限提取、必要文件检查与 JNI 推理测试后才标记为已安装。
- 离线模型基于语音停顿或最多 4 秒音频生成一条字幕，因此不会逐字显示流式 partial；X-ASR 仍可显示实时 partial。

请在真实 Android 设备上核对新模型的下载、首次加载速度、混合语言识别及持续录音体验。
