## Open Listener 0.1.15

- 本地语音模型及云端语音／翻译配置统一采用左侧方框勾选；只有实际选择的模型显示对号，已选云端配置底色跟随主题色，不再固定粉色。
- 本地语音模型的下载操作收进三个点菜单；已安装勾号紧随“已安装”状态显示；移除本地语音模型页的“检查配置”按钮。
- 云端配置编辑界面支持确认删除配置及其加密凭据；删除当前配置后自动切换到剩余配置，若无则恢复本地模型；按钮文案缩短为“保存”。
- 新增云端模型配置按钮固定为一个加号图标 + “添加配置”，避免重复加号。
- 深色模式录音首页引导文字使用白色。
- 胡萝卜开始按钮的颜色加深程度减半，保留录音按钮动画及其他主题色。
- 历史记录编辑模式直接在正文中修改原文与译文；修改过的段落显示保存／撤销操作，无需再打开编辑弹窗。

All Android builds and unit tests must pass before the signed release is published.
