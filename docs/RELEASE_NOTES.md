## Open Listener 0.1.12

- 前台通知直接显示实时原文或译文，设置中可切换显示语言；清除重复的 Open Listener 通知标题。
- 通知增加实时麦克风音量进度条，展开可显示更长的字幕；暂停/继续/结束操作保留。
- 精简英文按钮、标签和模型设置布局，减少窄屏界面的不必要换行。
- 外观中新增纯色背景开关（默认关闭），开启后移除动态渐变、光晕和颗粒。
- 录音历史改用可拖动进度条播放，播放/暂停按钮合并，进度条置于双语/原文/译文切换上方。
- 字幕模式的选中底色使用主题色；只查看译文时采用正文色，双语模式仍以主题色标识译文。
- 新增通知字幕模式与音量映射的单元测试。

Android 8+ · ARM64 手机下载 `OpenListener-v0.1.12-arm64-v8a.apk`，可通过原签名覆盖更新。
