# Ambient Precision

The maintained token/system specification is [../DESIGN.md](../DESIGN.md). The surface is an Android operating tool: clear bilingual paragraphs, three top tabs and one primary recording control. It uses no Hark assets, location, wallpaper service or downloaded fonts.

Compose supplies a local-time four-stage sky with slow drift, disabled when not visible, low battery/power-save, system animation scale zero or explicit reduced motion. RMS feedback uses real capture levels, not a synthetic meter. Dark/light and Chinese/English share the Material 3 structure and system typography.

Screenshots must come from the actual instrumented Android app. Tests label illustrative transcript fixtures as such. No generated mock is presented as a real device screenshot; capture evidence is pending until CI artifacts exist.
